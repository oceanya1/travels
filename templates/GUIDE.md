# Навигатор по файлам проекта

Что где лежит, что куда вписывать и в каком формате. Читать перед тем, как заполнять поездку.

## Карта файлов

| Что | Где | Зачем |
|---|---|---|
| Правила проекта | `CLAUDE.md` | Кто едет, порядок планирования, технические правила |
| Этот навигатор | `templates/GUIDE.md` | Форматы и адреса ячеек |
| Шаблон поездки | Google Drive → «Путешествия» → «Шаблон поездки» ([ссылка](https://docs.google.com/spreadsheets/d/1lIZVUeNGI2cG5wtVI2S8acUY1gRL2EdkkFavvRviR_4/edit)); копия в `templates/trip-template.xlsx` | Основа для каждой поездки. **Сам шаблон не заполнять** |
| Скрипт шаблона | `templates/build_trip_template.py` | Пересобирает xlsx, если меняется структура |
| Список вещей | `templates/packing-list.md` | Полный список с галочками и блоками по типу поездки |
| Список для Keep | `templates/packing-list-keep.txt` | Тот же список простым текстом для вставки в Google Keep |
| Папка поездки | `<страна>-<год>/README.md` | Статус, ссылки и заметки одной поездки |

## Новая поездка: порядок

1. Папка в репозитории: `<страна-латиницей>-<год>/`, например `korea-2027/`, `kazan-2026/`. Год — год начала поездки.
2. Копия шаблона в Drive через `copy_file` в папку «Путешествия». Название: `<Страна или город> <месяц год>`, например «Корея январь 2027».
3. Ссылку на таблицу записать в `README.md` поездки и на вкладку «Обзор».
4. Заполнять вкладки по правилам ниже.

## README.md поездки

```markdown
# <Страна>, <месяц(ы) год>

Путешественники: Аня и Саша.

## Ссылки
- Таблица: <ссылка на копию шаблона>
- Список вещей в Keep: <ссылка, если есть>
- Интерактивная страница: <ссылка, если есть>

## Статус
- <что решено, что забронировано, чего ждём от Ани>

## Решения
- <дата ДД.ММ.ГГГГ>: <что решили>

## Заметки
- <факты, найденные при подготовке, с источником>
```

## Таблица поездки: вкладки

Общие правила:
- **Синий текст** — поля для ввода. **Чёрный** — формулы, их не трогать. **Серый курсив** — пример, после заполнения удалить или заменить.
- Даты: `ДД.ММ.ГГГГ` (через API отправлять как `USER_ENTERED`, тогда Sheets распознаёт дату).
- Деньги: только число, без пробелов и знаков валюты (`45000`, не `45 000 ₽`).
- Значения в столбцах с выпадающим списком писать точно как в списке, иначе ячейка покажет ошибку.

### Обзор (поля в столбце B)

| Ячейка | Поле | Формат |
|---|---|---|
| A1 | Заголовок | `Поездка: <Страна>, <месяц год>` |
| B4 | Куда | Страна, города через запятую |
| B5 | Кто едет | `Аня, Саша` |
| B6 | Дата вылета | дата |
| B7 | Дата возвращения | дата |
| B8 | Дней в поездке | формула |
| B9 | Местная валюта | код: `KRW`, `USD`, `CNY`… |
| B10 | Курс | рублей за 1 единицу валюты, например `0.065` |
| B11 | Дата курса | дата, когда смотрели курс |
| B12 | Бюджет на двоих, ₽ | число |
| B13–B15 | Запланировано / потрачено / остаток | формулы |
| B16 | Список вещей | ссылка на заметку Keep |
| B17 | Интерактивная страница | ссылка |
| B18 | Заметки | свободный текст |

### Маршрут (строки 2–31, один день = одна строка)

| Столбец | Поле | Формат |
|---|---|---|
| A | День | номер, уже проставлен 1–30 |
| B, C | Дата, день недели | формулы от даты вылета |
| D | Город | где проводим день |
| E | План на день | коротко, через запятую или `; ` |
| F | Ночёвка | название отеля, сколько ночей |
| G | Переезды | `Откуда → куда: транспорт, время` |
| H | Заметки | свободно |

Если поездка длиннее 30 дней — скопировать формулы B:C вниз.

### Бюджет (строки 4–63)

| Столбец | Поле | Формат |
|---|---|---|
| A | Категория | список: Билеты, Жильё, Транспорт на месте, Еда, Развлечения и музеи, Покупки, Связь, Страховка, Документы и визы, Другое |
| B | Статья | что именно |
| C | План в местной валюте | число; пересчитается в рубли по курсу из «Обзора» |
| D | План в рублях | число, если цена сразу в рублях (билеты, страховка). Заполнять C **или** D |
| E | План итого, ₽ | формула |
| F | Факт, ₽ | сколько реально потратили, в рублях |
| G | Факт итого, ₽ | формула |
| H | Кто платил | список: Аня, Саша, Пополам |
| I | Комментарий | свободно |

Итоги: E2 (план) и G2 (факт). Сводка по категориям — столбцы K:M, формулы.

### Брони

| Столбец | Поле | Формат |
|---|---|---|
| A | Тип | список: Перелёт, Жильё, Поезд/автобус, Трансфер, Экскурсия, Страховка, Другое |
| B | Что | `Москва → Сеул, рейс …` / название отеля |
| C, D | С / По | даты |
| E | Статус | список: Ищем, Выбрали, Забронировано, Оплачено, Отменено |
| F | Стоимость, ₽ | число |
| G | Номер брони / ссылка | текст или URL |
| H | Бесплатная отмена до | дата |
| I | Распечатано? | список: да, нет, не нужно |
| J | Заметки | свободно |

Когда бронь оплачена — добавить строку и в «Бюджет» (факт).

### Места и еда

| Столбец | Поле | Формат |
|---|---|---|
| A | Город | |
| B | Название | |
| C | Тип | список: Достопримечательность, Музей, Еда, Кафе, Бар, Рынок / шопинг, Природа, Другое |
| D | Район / адрес | |
| E | Ссылка | карта или отзывы |
| F | Приоритет | список: Обязательно, Хорошо бы, Если будет время |
| G | Были? | список: да, нет |
| H | Впечатления | после поездки |

### Документы

Строки — пункты (паспорт, виза/разрешение, страховка, военный билет, карты, связь…). Столбцы B (Аня) и C (Саша) — статус из списка: нужно сделать, в процессе, готово, не нужно. D — срок или дата окончания действия. E — комментарий и источник.

## Список вещей

- Основа — `templates/packing-list.md`: блоки «Документы и деньги», «Аня», «Саша», «Общее», «Аптечка» берутся всегда, плюс подходящие добавки «Море и жара», «Зима и холод», «Заграница».
- В Keep Аня вставляет текст сама: по одной вещи на строку, каждый блок — отдельная заметка, затем «Показать флажки». Готовый текст — `templates/packing-list-keep.txt`.
- Если по итогам поездки список поменялся — обновить оба файла (`.md` и `-keep.txt`).
